# Reference — Claims Escalation Matrix
**Owner:** Claims Operations | **Effective:** 2025-07-01

| Situation | First escalation | Final authority |
|---|---|---|
| Settlement disputed by insured | Team lead | Claims Manager |
| Payment above adjuster authority ($25,000) | Claims Manager | Claims Executive |
| Coverage question or reservation of rights | Coverage counsel | Claims Executive |
| Suspected fraud | SIU manager | Claims Executive |
| Total loss valuation challenged | Total loss unit lead | Appraisal process where a state amendment provides it |
| Complaint from a state regulator | Compliance | Claims Executive |
| Repair quality dispute at a network shop | DRP program manager | Claims Manager |

## Notes
- Escalation is documented in the file with the date, the person contacted, and the outcome.
- An insured who asks to speak to a supervisor is transferred within one business day.
- Where a state amendment provides an appraisal remedy, valuation disputes follow that process instead of internal escalation.
