# Reference — Deductible Schedule
**Owner:** Product | **Effective:** 2025-07-01

Deductibles apply per loss, per vehicle, and are subtracted from the settlement amount.

| Coverage | Personal auto options | Fleet default |
|---|---|---|
| Collision | $250 / $500 / $1,000 / $2,000 | $1,000 |
| Comprehensive | $100 / $250 / $500 / $1,000 | $1,000 |
| Glass (see note) | Same as comprehensive | Same as comprehensive |

## Notes
- The deductible shown on the declarations page controls. This schedule lists available options only.
- **Glass losses take the comprehensive deductible.** There is no separate glass deductible on either form.
- Where a single event damages two scheduled vehicles, a deductible applies to each vehicle.
- Deductibles are not prorated and are not waived for a first claim.
